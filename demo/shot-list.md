# Recording shot list

## Setup

- Use 1920×1080 or 2560×1440, browser zoom 90–100%, notifications off.
- Start from a fresh case and empty activity ledger.
- Keep the app, target agent chat, and site-tool activity visible without exposing personal tabs or tokens.
- Confirm the green “9 site tools registered” badge before recording.
- Record system/app audio or add the supplied voiceover afterward; the final public YouTube video must include audio.

## Takes

1. **Clean overview (12s):** slow pointer pass over object, empty timeline, sources, and tool status.
2. **Tool proof (15s):** available tools and annotations; ensure names are readable.
3. **Golden prompt (26s):** real-time or lightly speed-ramped calls; no cuts that conceal errors.
4. **Evidence result (17s):** gap, S6 contradiction, graph edges, cited label.
5. **Injection test (18s):** prompt, S8 card, agent response, unchanged gap.
6. **Human co-edit (21s):** visible S4 click, draft invalidation, stale recovery, revised wording.
7. **Approval/export (24s):** capture premature failure, visible checkbox/click, receipt, Markdown and JSON links.
8. **Closing proof (19s):** ledger attribution, terminal `npm test`, repository root and MIT license.

## Editing notes

- Add lower-thirds for tool names, `untrustedContentHint`, `stale_state`, and `approval_required`.
- Use one subtle highlight box around the unchanged gap during the S8 beat.
- Do not label source visibility, deployment, native validation, or YouTube upload “passed” until each is verifiable.
- Keep final runtime at or below 2:45 to leave platform encoding margin.
